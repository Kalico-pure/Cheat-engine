关于Cheat Engine
Cheat Engine 是一款专为修改单机游戏而设计的工具（需在无网络连接环境中使用），可让你根据喜好调整游戏难度（例如：觉得100点生命值太简单？试试将上限改为1点生命值挑战自己）。除此之外，它还包含多种实用工具，可用于调试游戏甚至普通应用程序，并通过检查内存修改帮助你防范后门攻击，甚至提供了一些方法让隐藏的威胁无从遁形。
功能亮点：
• 内存扫描器：快速定位并修改游戏中的变量
• 调试器、反汇编器、汇编器
• Speedhack（速度调节）
• 训练器制作工具
• Direct3D 操作工具
• 系统检测工具（对程序员和软件分析师同样实用）
此外，Cheat Engine 提供强大的脚本支持，方便资深开发者轻松创建自定义应用并分享给他人。

关于 DBVM
DBVM（内核调试虚拟机）是一种可接管操作系统的虚拟化环境，通过扩展指令集允许用户态程序访问内核态功能，并具备重定向系统事件流的能力（例如：无需修改中断表即可将中断跳转到自定义处理程序）。
与Cheat Engine的协同
Cheat Engine 利用这些扩展指令极大简化游戏修改与调试流程，尤其在Vista 64位系统上表现突出。只需以DBVM模式启动系统（DBVM会随后加载Windows等操作系统），Cheat Engine将自动检测DBVM并启用增强功能。
安全机制
DBVM可能被恶意软件滥用，因此要求160位密钥才允许调用指令。其中一条指令专门用于修改默认密钥，确保其他程序无法在未获授权时使用DBVM功能。

常见问题解答（FAQ）
基本问题
问：Cheat Engine是什么？
答：Cheat Engine是一款帮助您分析并修改游戏/应用程序的工具，支持强大的脚本功能，几乎能实现任何自定义需求。详情请查看"关于"页面。
问：如何安装Cheat Engine？
答：在主页面点击下载按钮，运行安装程序即可。
问：如何卸载Cheat Engine？
答：可通过开始菜单的卸载选项，或在Windows设置→应用→卸载程序中操作。

答：不会，且此类邮件可能激怒他。

问：能用它破解其他软件或获取付费内容吗？
答：禁止。仅允许合法用途（欧洲等地区允许逆向工程自用除外）。
